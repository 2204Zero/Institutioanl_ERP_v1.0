# Phase 10 Examination REST API Reference Specifications

### `GET /api/v1/exams/timetable`
Fetch collision-free examination timetable schedule.

### `GET /api/v1/exams/hall-ticket/{studentRollNo}`
Generate signed Hall Ticket PDF with QR payload.

### `POST /api/v1/exams/results/publish`
Publish final semester results to student portals.
