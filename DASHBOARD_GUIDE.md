# Multi-Role Dashboard Navigation & User Guide (Phase 11)

## 1. Role-Based View Customization
The Phase 11 Analytics Platform dynamically tailors KPI cards and default charts depending on the selected user role:

- **Principal View**: Displays macro-institutional health metrics (revenue, expenses, total enrollment, placement rate, Scopus publication count).
- **Department Head View**: Focuses on branch-specific academic health, subject difficulty indices, and student backlog counts.
- **Finance Officer View**: Focuses on fee collection channels, outstanding departmental dues, and payroll disbursal.
- **Student View**: Highlights personal CGPA progress, attendance status, library loan status, and fee clearance.
- **HR Manager View**: Focuses on faculty turnover, monthly payroll trends, leave statistics, and recruitment funnels.

---

## 2. Workspace Tabs & Interaction

```
[ Executive BI Dashboard ] [ Domain Intelligence ] [ AI Predictive Hub ] [ NL Search ] [ Reports ]
```

1. **Executive BI Dashboard**: High-level institutional KPIs and macro trend charts.
2. **Domain Intelligence**: Sub-tabs for deep-dive analysis across Student, Finance, Faculty, Library, Hostel, Transport, Examination, and HR modules.
3. **AI Predictive Hub**: Active ML risk predictions with confidence %, feature importance, and model performance benchmarks.
4. **Natural Language Search**: Conversational query input for instant query execution.
5. **Report Engine**: Management of scheduled automated report dispatches.
