TC_VAL_001: Input Validation Failure - Missing Required Fields
--------------------------------------------------------------------------------
Objective   : Verify that submitting a Student profile with missing required fields
              triggers a 400 Bad Request with granular field validation errors.
Method / URI: POST /api/v1/students
Input Body  :
{
  "rollNumber": "",
  "firstName": null,
  "lastName": null,
  "email": "invalid-email-string",
  "phone": null,
  "department": null,
  "batch": null
}
Expected HTTP Code  : 400 BAD REQUEST
Expected Output Body:
{
  "status": 400,
  "error": "Validation Failed",
  "message": "Input payload contains validation errors",
  "path": "/api/v1/students",
  "validationErrors": {
    "rollNumber": "Roll number is required",
    "firstName": "First name is required",
    "lastName": "Last name is required",
    "email": "Invalid email format",
    "phone": "Phone number is required",
    "department": "Department is required",
    "batch": "Batch is required",
    "dateOfBirth": "Date of birth is required",
    "enrollmentDate": "Enrollment date is required",
    "gender": "Gender is required"
  }
}
Actual Result       : 400 Bad Request with exact field level messages from GlobalExceptionHandler.
Status              : PASS

TC_VAL_002: Unique Constraint Conflict - Duplicate Roll Number
--------------------------------------------------------------------------------
Objective   : Verify that attempting to register an existing roll number returns
              a 409 Conflict exception.
Method / URI: POST /api/v1/students
Input Body  : Payload with "rollNumber": "2024-CSE-001" (already registered)
Expected HTTP Code  : 409 CONFLICT
Expected Output Body:
{
  "status": 409,
  "error": "Conflict",
  "message": "Roll number already exists: 2024-CSE-001",
  "path": "/api/v1/students"
}
Actual Result       : 409 Conflict. Duplicate entry prevented.
Status              : PASS
