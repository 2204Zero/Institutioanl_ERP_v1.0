TC_DOC_001: Upload Document - Aadhaar Card
--------------------------------------------------------------------------------
Objective   : Upload student's Aadhaar PDF and store file on disk with DB record.
Method / URI: POST /api/v1/students/{studentId}/documents
Content-Type: multipart/form-data
Function    : StudentDocumentController.uploadDocument(studentId, documentType, file)
Input Form  :
    - studentId   : 1
    - documentType: AADHAAR
    - file        : aadhaar_card_sample.pdf (Binary bytes)
Expected HTTP Code  : 201 CREATED
Expected Output Body:
{
  "success": true,
  "message": "Document uploaded successfully",
  "data": {
    "id": 1,
    "studentId": 1,
    "documentType": "AADHAAR",
    "fileName": "1_AADHAAR_3b8a1c92.pdf",
    "originalFileName": "aadhaar_card_sample.pdf",
    "fileType": "application/pdf",
    "fileSize": 102400,
    "formattedSize": "100.00 KB",
    "downloadUrl": "/api/v1/documents/1/download",
    "viewUrl": "/api/v1/documents/1/view",
    "uploadedAt": "2026-09-27T19:45:59.781602"
  }
}
Actual Result       : 201 Created. File saved under uploads/documents/, metadata in DB.
Status              : PASS

TC_DOC_005: View Document Inline Preview (Browser View)
--------------------------------------------------------------------------------

Function    : StudentDocumentController.viewDocument(Long id)
Expected HTTP Code    : 200 OK

    - Content-Type       : application/pdf
    - Content-Disposition: inline; filename="aadhaar_card_sample.pdf"
