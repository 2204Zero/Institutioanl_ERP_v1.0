TC_STS_001: Status Transition - ACTIVE to SUSPENDED
--------------------------------------------------------------------------------
Objective   : Update student status from ACTIVE to SUSPENDED with mandatory reason.
Method / URI: PATCH /api/v1/students/{id}/status  (e.g., id = 1)
Function    : StudentController.updateStudentStatus(Long id, StudentStatusUpdateDto)
Input Body  :
{
  "status": "SUSPENDED",
  "reason": "Attendance shortage below minimum 60% requirement in Semester 2",
  "changedBy": "dean_academics"
}
Expected HTTP Code  : 200 OK
Expected Output Body:
{
  "success": true,
  "message": "Student status updated successfully",
  "data": {
    "id": 1,
    "rollNumber": "2024-CSE-001",
    "fullName": "Aarav Sharma",
    "status": "SUSPENDED",
    "updatedAt": "2026-09-27T19:45:59.817476"
  }
}
Actual Result       : 200 OK. Student status updated to SUSPENDED. New audit record created.
Status              : PASS
