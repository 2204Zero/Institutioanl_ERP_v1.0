# Responsive & Accessibility Design Guide

## 1. Breakpoint Standards
- `sm` (640px): Mobile Landscape
- `md` (768px): Tablet View
- `lg` (1024px): Laptop Layout
- `xl` (1280px): Desktop Grid
- `2xl` (1536px): Ultra-Wide Workstation

## 2. Touch Target & Accessibility Requirements
- **Touch Target**: Minimum 44px x 44px clickable target for touch input elements.
- **Focus Rings**: High contrast `ring-2 ring-brand-500 ring-offset-2` on all focusable elements (`<button>`, `<input>`, `<select>`, `<a>`).
- **Keyboard Navigation**: Native tab navigation, Esc modal dismissal, and Cmd+K command palette keybindings.
