# Hostel Module Overview & Subsystem Scope

## 1. Structure & Blocks
- **Campus Buildings**: Ramanujan Boys Hostel Block A, Kalpana Chawla Girls Hostel Block B, International Scholars Block C.
- **Room Types**: Single, Double, Triple, and Dormitory layouts. AC and Non-AC configurations.
- **Student Profile Binding**: Binds room number and bed code (`A-203-BED1`) directly to student profiles in SIS.
