# Institutional ERP Suite — Executive Finance Dashboard & UI Layout

## 1. UI Component Architecture
The Finance Dashboard UI (`src/pages/FinanceDashboardPage.tsx`) presents a multi-tab workspace:
- **Executive Overview**: KPI Cards, Recharts collection trends, activity feed.
- **Fee Structures**: Card grid of program templates with freeze/revision status.
- **Student Invoices**: Real-time table with PDF download triggers.
- **Scholarships & Aid**: Verification dashboard with approval triggers.
- **General Ledger**: Chart of accounts & trial balance statement.
- **Parent Portal View**: Multi-installment gateway payment launcher & tax certificates.
- **BI Reports & Auditing**: Terminal log feed and data exports.

---

## 2. Design System Alignment
- Follows 8px spatial grid, Inter font typography, WCAG AA compliance, and dark/light Tailwind variables (`bg-slate-900`, `text-slate-300`, `bg-brand-600`).
