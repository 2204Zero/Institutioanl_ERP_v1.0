# Enterprise Book Management & Cataloging Subsystem

## 1. Catalog Attributes
Comprehensive catalog metadata supported:
- **Identifiers**: Book ID (`LIB-BK-9012`), ISBN (`978-0131103627`), Barcode (`BC-901238`), QR Code Payload.
- **Bibliographic Details**: Title, Subtitle, Edition, Language, Author, Co-Author, Publisher, Pub Year, Category, Department, Subject, Keywords.
- **Physical Location**: Shelf, Rack, Floor, Campus, Branch Code.
- **Inventory Metrics**: Total copies, available copies, price, supplier, purchase date, condition (`NEW`, `GOOD`, `FAIR`, `DAMAGED`).

---

## 2. CRUD & Archival Operations
- Supports Create, Update, Delete, Archive, Restore, Search, Filter, and CSV Export.
