# Library Membership & QR / RFID Access Subsystem

## 1. Membership Verification Standards
- **QR Membership Card**: Dynamic barcode/QR displayed on Student & Faculty mobile app.
- **RFID Pass Scanning**: High-speed turnstile gate check-in at library entrance.
- **Validity & Status Rules**: Membership automatically suspends if outstanding library fines exceed ₹500 or if student status is set to `GRADUATED` or `SUSPENDED`.
