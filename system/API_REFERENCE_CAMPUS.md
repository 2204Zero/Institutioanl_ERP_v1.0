# Institutional ERP Suite — Phase 8 Campus Operations REST API Reference

## 1. REST Endpoints Catalog

### `GET /api/v1/campus/library/books`
Fetch cataloged volumes with ISBN search filter.

### `POST /api/v1/campus/hostel/allocate`
Allocate hostel room bed to a student.

### `POST /api/v1/campus/maintenance/tickets`
Log a maintenance work order ticket.
